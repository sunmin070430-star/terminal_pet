# 🐾 터미널 애완동물 키우기 (날씨 API 버전)

## 1\. 게임 소개

터미널에서 고양이나 강아지를 입양해 키우는 텍스트 게임입니다. 펫은 **배부름, 기분, 체력** 세 가지 수치(0\~100)를 가지며, 사용자는 밥 주기, 놀아 주기(가위바위보), 재우기로 펫을 돌봅니다. 상태는 `pet_save.json`에 저장되어 다음 실행 때 이어서 플레이할 수 있고, 게임을 꺼 둔 시간만큼 수치가 줄어듭니다.

### 이번에 추가한 날씨 기능

5주차 버전에 **Open-Meteo API로 서울의 실시간 날씨를 가져와 펫에게 반영하는 기능**을 추가했습니다.

|날씨|기분 변화|펫의 한마디|
|-|-|-|
|맑음|+5|햇살이 좋아요! ○○가 신나서 꼬리를 흔들어요.|
|흐림|변화 없음|하늘이 흐려요. ○○가 조용히 쉬고 있어요.|
|비|-5|밖에 비가 와요. ○○가 창밖만 보고 있어요.|
|눈|-5|밖에 눈이 와요. ○○가 추워서 몸을 웅크렸어요.|

상태 화면 맨 위에는 `오늘 날씨: 흐림 15.7°C`처럼 현재 날씨와 기온이 표시됩니다. 인터넷 연결 문제 등으로 날씨를 가져오지 못하면 안내 메시지를 보여 주고 날씨 효과 없이 원래 게임대로 진행합니다.

## 2\. 실행 방법

[uv](https://docs.astral.sh/uv/)가 설치되어 있어야 합니다. Python은 uv가 `pyproject.toml`에 맞는 버전을 자동으로 준비합니다.

```bash
git clone https://github.com/sunmin070430-star/terminal_pet.git
cd terminal_pet
uv sync
uv run terminal_pet_test.py
```

`uv sync`는 `uv.lock`에 기록된 정확한 버전의 패키지(`requests` 등)를 `.venv`에 설치하므로, 어느 컴퓨터에서든 같은 환경이 재현됩니다. 날씨 함수만 따로 확인하려면 `uv run weather.py`를 실행하면 `{'weather': '흐림', 'temperature': 15.7}` 같은 결과가 출력됩니다.

**API 키는 필요 없습니다.** Open-Meteo는 비상업적 용도에 한해 키 없이 무료로 사용할 수 있어 `.env` 파일을 만들 필요가 없습니다. (`.gitignore`에는 혹시 모를 키 유출을 막기 위해 `.env`를 포함해 두었습니다.)

## 4\. 주요 클래스와 함수

### `weather.py`

**`get_weather()`** — 서울(위도 37.57, 경도 126.98)의 현재 날씨를 가져옵니다.

1. 요청 조건을 `params` 딕셔너리로 만들고, `requests.get()`으로 Open-Meteo에 GET 요청을 보냅니다. `timeout=5`를 주어 5초 안에 응답이 없으면 포기하므로, 네트워크가 느려도 게임이 멈추지 않습니다.
2. `raise_for_status()`로 404·500 같은 HTTP 오류 응답을 예외로 바꿉니다. 이 줄이 없으면 오류 응답을 정상 데이터처럼 처리하려다 엉뚱한 곳에서 실패합니다.
3. `response.json()["current"]`로 응답 JSON에서 현재 날씨 부분만 꺼내, `{"weather": "흐림", "temperature": 15.7}` 형태의 딕셔너리로 반환합니다.
4. 실패하면 `None`을 반환합니다. 잡는 예외는 네트워크·시간 초과·HTTP 오류(`requests.RequestException`), 응답에 기대한 키가 없는 경우(`KeyError`), 응답이 올바른 JSON이 아닌 경우(`ValueError`) 세 가지입니다. 예외를 함수 안에서 처리하기 때문에 호출하는 쪽은 결과가 `None`인지만 확인하면 됩니다.

**`code_to_weather(code)`** — API가 주는 WMO 날씨 코드(숫자)를 네 가지 한글 상태로 바꿉니다. 0·1(맑음, 대체로 맑음)은 "맑음", 2·3(구름 조금, 흐림)과 45·48(안개)은 "흐림", 71\~77(눈)과 85·86(소낙눈)은 "눈"입니다. 나머지인 이슬비(51\~57), 비(61\~67), 소나기(80\~82), 뇌우(95\~99)는 모두 "비"로 처리합니다. 비 계열 코드가 가장 많아서 조건을 일일이 쓰지 않고 마지막 기본값으로 두었습니다.

### `terminal_pet_test.py` — `Pet` 클래스

|메서드|동작|
|-|-|
|`__init__()`|이름, 종류, 세 수치(기본 70), 마지막 저장 시각을 설정. 저장 시각이 없으면 현재 시각을 사용|
|`clamp_stats()`|세 수치를 `max(0, min(100, 값))`으로 0\~100 범위에 고정. 수치를 바꾸는 모든 메서드가 마지막에 호출|
|`apply_offline_decay()`|현재 시각과 `last_time`의 차이로 꺼 둔 시간을 계산해 안내하고, **10분당** 배부름·기분 -2, 체력 -1을 적용. 5초 미만이면 무시|
|`feed()`|배부름 +25. 이미 90 이상이면 "배가 빵빵하다"며 거부|
|`play()`|가위바위보 미니게임. 체력이 20 이하면 거부. 결과에 따라 기분 +30(승)/+15(무)/+20(패)이고, 공통으로 체력 -15, 배부름 -10. 승패는 (내 선택, 펫 선택) 튜플이 이기는 조합 목록에 있는지로 판정|
|`sleep()`|체력 +40, 배부름 -5|
|`natural_decay()`|행동 한 번 할 때마다 배부름·기분 -2. 잘못된 입력일 때는 `continue`로 건너뛰어 적용되지 않음|
|`apply_weather(weather)`|**이번에 추가.** 날씨 문자열에 따라 기분을 ±5 하고 한마디를 출력. 흐림은 `else`에서 메시지만 출력|
|`get_face()`|세 수치 중 하나라도 20 이하이거나 평균이 40 미만이면 `T.T`, 평균 70 이상이면 `^.^`, 그 외 `o.o`|
|`print_status(weather_text=None)`|ASCII 그림, 상태 막대(값 10당 ■ 한 칸), 경고 메시지를 출력. **이번에 매개변수를 추가**해 날씨 문자열이 있으면 화면 맨 위에 표시. 기본값이 `None`이라 날씨가 없으면 그 줄을 생략|
|`to_dict()`|저장용 딕셔너리 반환. `last_time`에 **저장하는 순간의 시각**을 넣어 다음 실행 때 꺼 둔 시간을 계산할 수 있게 함|

### `terminal_pet_test.py` — 그 밖의 함수

* **`save_pet()` / `load_pet()`**: `pet_save.json`에 UTF-8로 저장하고 불러옵니다. 한글 이름이 깨지지 않도록 `ensure_ascii=False`를 사용합니다. 불러올 때 파일이 없거나 손상되었으면 `None`을 반환해 새 펫 입양으로 넘어갑니다.
* **`create_new_pet()`**: 빈 이름을 막는 `while` 문과 1·2만 받는 `while` 문으로 입력을 검증한 뒤 새 `Pet`을 만듭니다.
* **`main()`**: 실행 순서는 ① 저장된 펫 불러오기(없으면 입양) → ② 오프라인 감소 적용 → ③ **`get_weather()`를 한 번 호출해 날씨 효과 적용** → ④ 행동 선택 반복문입니다. 날씨 호출을 반복문 **밖**에 둔 이유는, 안에 두면 행동할 때마다 API를 호출하고 기분도 매번 ±5가 되기 때문입니다. 날씨 문자열은 한 번 만들어 `weather_text`에 저장해 두고 반복문에서 재사용합니다.

## 5\. Open-Meteo API 사용 방법

요청 주소와 매개변수는 다음과 같습니다.

```
GET https://api.open-meteo.com/v1/forecast
    ?latitude=37.57&longitude=126.98&current=temperature_2m,weather_code
```

`current`에 원하는 항목을 쉼표로 나열하면 그 값만 돌려줍니다. 여기서는 지상 2m 기온(`temperature_2m`)과 날씨 코드(`weather_code`)를 요청합니다. 응답은 아래와 같은 JSON이며, 코드에서는 `current` 안의 두 값만 사용합니다.

```json
{
  "current": {
    "time": "2026-11-04T16:45",
    "temperature_2m": 15.7,
    "weather_code": 3
  }
}
```

인증이 필요 없는 공개 API라서 요청에 키를 넣지 않으며, 제출 시에도 별도의 키는 없습니다.

## 6\. 한계점

* **날씨 효과는 게임을 실행할 때마다 한 번 적용됩니다.** 날씨를 적용한 날짜를 저장하지 않기 때문에, 맑은 날 게임을 껐다 켜기를 반복하면 기분 +5를 계속 받을 수 있습니다. 개선하려면 `to_dict()`에 마지막으로 날씨를 적용한 날짜를 저장하고, 같은 날이면 건너뛰도록 하면 됩니다.
* 날씨는 실행 시점에 한 번만 가져오므로, 게임을 오래 켜 두면 화면의 날씨가 실제와 달라질 수 있습니다.
* 위치가 서울로 고정되어 있습니다. `weather.py`의 `SEOUL_LAT`, `SEOUL_LON` 상수만 바꾸면 다른 지역에도 적용할 수 있습니다.
* 날씨를 네 가지로 단순화했기 때문에 안개는 "흐림", 뇌우는 "비"로 처리됩니다.
